# StrapSeason Diet
## React + TypeScript + Vite

An application that helps busy professionals get in the best shape of their lives
Inspired by MyFitnessPal and Streaktracker.com 
## Main Functionality
1. Streak Tracker
According to science, our habits formed the best when we see the progress we are making daily. Therefore, I have implemented this, with a green streak to help users easily visualise the progress they are making.
2. Calendar Insight
3. Motivational Quotes
Check it out at : Strapseasons.com
